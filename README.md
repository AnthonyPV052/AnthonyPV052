### 💻 Proyecto Destacado

#### 🤖 Plataforma Digital Interna (Proyecto Monorepo Académico)
*Plataforma diseñada para una cadena de restaurantes, centralizando operaciones, incidencias, inventarios, proveedores, telemetría, un agente de soporte de IA y pipelines de datos.*

*   📄 **Automatización de RFP:** Implementé un sistema automatizado de ingesta de RFPs que lee archivos PDF, utiliza LLMs para analizar la información y genera tickets para aprobación o rechazo humano.
*   🧠 **Agente de Soporte:** Diseñé un agente utilizando **RAG** y **herramientas MCP** para información corporativa y seguimiento de incidencias. Implementé memoria persistente para el agente usando **PostgreSQL** y **pgvector**.
*   🔗 **Integración Full-Stack:** Conecté múltiples frontends en **Next.js 16** con una API central en **FastAPI**, agentes de **LangGraph**, telemetría y colas de tareas con **Celery**.
*   🐳 **Infraestructura:** Despliegue y soporte con **Docker Compose**, **Redis**, **Qdrant** y **PostgreSQL/Supabase**.
